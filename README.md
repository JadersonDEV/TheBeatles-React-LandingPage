Trabalho Individual - The Beatles (React) 🎸
Site single-page focado na história dos The Beatles, com ênfase na trajetória de George Harrison e no legado da banda, desenvolvido em React e Vite.

🖤 O Conceito Visual (Preto e Branco) Mantive a ideia do design focado no preto e branco editorial, estilo revista antiga, remetendo aos anos 60. O visual continua minimalista e atemporal, unindo contrastes de fundo escuro com textos claros e imagens tratadas.

🛠️ Tecnologias Utilizadas (Stack) O projeto foi totalmente reestruturado para uma arquitetura moderna baseada em componentes:

React + Vite: Para componentização da interface e alta performance de build.
JavaScript: Gerenciamento de lógica e interatividade.
CSS3 / Estilização Modular: Mantendo as variáveis de cores (--preto, --branco), tipografia padronizada e animações fluidas para os elementos visuais.
Bootstrap 5: Utilizado para garantir a responsividade do layout e o suporte a componentes estruturais e grids.
📄 Nova Estrutura do Site (Single Page / Smooth Scroll) Para este trabalho individual, o projeto foi reduzido e unificado em uma única página com rolagem suave contínua (smooth scroll), contendo as seguintes seções principais:

Início (Hero / Home): A porta de entrada do site, com apresentação visual marcante e atalhos rápidos.
George Harrison: Seção dedicada à história, trajetória e importância do músico dentro e fora da banda.
Legado: Conteúdo visual dinâmico destacando a influência cultural atemporal dos Beatles, acompanhado de vídeos integrados.
